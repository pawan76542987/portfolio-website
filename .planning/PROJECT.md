# Pawan Uniyara — Digital Engineering Laboratory

## Project Overview

A production-grade, highly responsive, cinematic engineering portfolio website for **Pawan Uniyara** (Full-Stack Developer • CSE AI/ML Undergraduate). Designed around the **"Digital Engineering Laboratory"** aesthetic — combining computer science fundamentals, full-stack Next.js/React craftsmanship, and creative 3D WebGL computation.

---

## Active Milestone: v1.1 — Interactive 3D & Creative Engineering

### Core Milestone Objectives
1. **Interactive 3D Simulation Engine**: Upgrade the Three.js WebGL system to support multiple visual simulation modes (Computational Node Matrix, Particle Nebula, Quantum Vortex) with real-time HUD controls.
2. **Gravitational Cursor Physics**: Implement proximity-based force vectors, spring dynamics, and mouse velocity interaction with 3D nodes and particles.
3. **Ambient Background 3D Depth**: Extend ambient spatial depth and subtle GPU-accelerated shader layers across page sections for visual continuity.
4. **Web Audio Micro-Interaction Synthesizer**: Integrate a lightweight, zero-asset Web Audio API synthesizer for tactile UI audio feedback with global mute controls and persistence.
5. **Strict Performance & A11y Guardrails**: Maintain 60fps rendering, adaptive DPR, `IntersectionObserver` loop pausing, and full `prefers-reduced-motion` compliance.

---

## Technical Stack Summary
- **Framework**: Next.js 15 (App Router, SSG)
- **Language**: TypeScript (100% strict)
- **UI Library**: React 19
- **3D & Shaders**: Three.js (WebGL, Custom Shaders, Particle Systems)
- **Styling**: Vanilla CSS Design Tokens + CSS Modules
- **Audio**: Web Audio API (Synthesized oscillators, zero network assets)
- **Deployment**: Vercel
